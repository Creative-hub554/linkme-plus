/*
 * The default border colour, in `@layer base` deliberately.
 *
 * This was written bare, and bare CSS beats *every* layer regardless of
 * specificity — while Tailwind v4 puts its utilities in `@layer utilities`. So
 * this one rule, which exists only to give borders a default, was overriding
 * every `border-<colour>` class in the application. Before the fix, every
 * border-coloured element on three pages computed to exactly this slate: 27 of
 * 27 on `/settings`, 13 of 13 on `/login`, 27 of 27 on `/feed` — including
 * `border-white/20`, `border-navy-700` and `border-brand-purple/20`, which have
 * nothing to do with it.
 *
 * In `base` it is a default again — it still applies wherever nothing says
 * otherwise, and a utility can now override it.
 */
@layer base {
  * {
    border-color: hsl(var(--border));
  }
}
